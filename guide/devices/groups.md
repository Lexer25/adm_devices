# Управление группами точек прохода {#devices-groups}

## Назначение {#devices-groups-purpose}

Страница **«Группы точек прохода»** (`devices/groups`) выполняет одну команду
управления сразу для **набора точек прохода**. Набор можно задать тремя способами
(и комбинировать их):

1. **группами устройств** (таблица `DEVGROUP`) — включая вложенные группы;
2. **флажками точек прохода** в списке (по контроллерам);
3. **перечнем `ID_DEV`** строкой — например, `483,484 508;512`.

Команды те же, что и в панели «Контроллеры», поэтому поведение оборудования
одинаковое — разница только в способе выбора точек прохода и в способе запуска.

## Как открыть {#devices-groups-open}

- Раздел **«Устройства»** → кнопка **«Группы точек прохода»** в верхней панели;
- либо прямой адрес: `devices/groups`
  (например, `http://<сервер>/city/index.php/devices/groups`).

[!!] Страница доступна только администратору. Для остальных пользователей
выполняется переход на страницу сообщения об ошибке, а попытка отказа
записывается в лог приложения.

## Команды {#devices-groups-commands}

| Команда | Код | Что делает |
| --- | --- | --- |
| **Открыть 1 раз** | `opendoor` | Разовый проход: контроллер открывает точку прохода и закрывает её сам |
| **Открыть навсегда** | `opendooralways` | Контроллер держит точку прохода открытой **до следующей команды** |
| **Закрыть навсегда** | `lockdoor` | Контроллер держит точку прохода закрытой **до следующей команды** |
| **Разблокировать** | `unlockdoor` | Снимает блокировку точки прохода |

Команды «Открыть навсегда» и «Закрыть навсегда» помечены в интерфейсе значком
**режим**: они не разовые, а меняют состояние точки прохода до отмены. Для них
окно подтверждения выводит дополнительное предупреждение.

## Способ 1. Группы точек прохода {#devices-groups-by-group}

В средней колонке страницы выводится дерево групп устройств
(раздел **«Группы устройств»**, таблица `DEVGROUP`):

- дерево повторяет иерархию групп: вложенные группы показаны с отступом;
- в колонке **«Точек прохода»** указано количество точек прохода в группе
  **с учётом вложенных групп**; если в самой группе их меньше, рядом в скобках
  выводится «*N* в самой группе»;
- флажок группы отмечает и все вложенные группы (снимается так же);
- группы, в которых нет точек прохода, **показаны, но выбрать их нельзя**
  (флажок отключён, вместо количества — «нет точек прохода»). Это сделано,
  чтобы список групп совпадал с разделом «Группы устройств», но команда
  не уходила «в пустоту»;
- флажок **в шапке таблицы** отмечает все группы, в которых есть точки прохода.

Итоговый набор — объединение всех отмеченных групп со всеми вложенными в них
группами.

## Способ 2. Флажки точек прохода {#devices-groups-by-points}

В правой колонке выводится **перечень точек прохода**, сгруппированный по
контроллерам:

- у каждой точки прохода показаны название, `ID_DEV` и номер считывателя;
- у контроллера есть флажок **«все»** — отметить все его точки прохода;
- над списком — флажок **«Отметить все точки прохода»**;
- под списком — счётчик **«Отмечено точек прохода»** (считает только флажки).

Этот способ удобен, когда нужно открыть не всю группу, а несколько конкретных
точек прохода, в том числе из разных групп.

## Способ 3. Набор точек прохода (ID_DEV) {#devices-groups-by-ids}

Поле **«Набор точек прохода (ID_DEV)»** принимает список идентификаторов
`DEVICE.ID_DEV`:

- разделители — запятая, точка с запятой или пробел: `483,484`, `483;484`,
  `483 484`;
- можно указывать идентификаторы, которых нет в списке выше — например,
  полученные из отчёта или из другого раздела;
- идентификаторы, не являющиеся точками прохода (контроллеры, серверы,
  несуществующие устройства), **отбрасываются** — команда им не отправляется.

## Объединение способов {#devices-groups-combine}

Все три способа складываются: отмеченные группы + отмеченные флажки + список
`ID_DEV`. Повторы автоматически убираются, команда выполняется для каждой
точки прохода ровно один раз.

## Порядок выполнения {#devices-groups-flow}

1. Выберите команду, отметьте группы и (или) точки прохода, при необходимости
   впишите перечень `ID_DEV`.
2. Нажмите **«Выполнить команду»**.
3. Браузер запросит подтверждение и покажет, что именно будет выполнено:
   команду, количество отмеченных точек прохода, количество групп и набор
   `ID_DEV`. Для команд-режимов добавится предупреждение.
4. После отправки формы сервер:
   - проверяет права администратора и CSRF-токен;
   - раскрывает группы в точки прохода и оставляет только существующие
     точки прохода;
   - отправляет команду каждому контроллеру через транспортный сервер;
   - выдерживает паузу **2 секунды** и опрашивает новое состояние точек прохода.
5. Страница перезагружается и показывает **панель результата**.

[!!] Из-за паузы и опроса состояния ответ страницы для большого набора
(десятки контроллеров) приходит не мгновенно — это нормально. Обновление
страницы (F5) команду **не повторяет**: результат показывается после
перенаправления (Post/Redirect/Get).

## Панель результата {#devices-groups-result}

Зелёная панель содержит:

- выполненную команду и время окончания;
- количество точек прохода, для которых команда выполнена;
- список групп, по которым сработало (полный путь группы);
- таблицу точек прохода: `ID_DEV`, название, считыватель, контроллер,
  транспортный сервер;
- раскрывающийся блок **«Подробный журнал выполнения команды»** — ответ
  контроллера по каждой точке прохода и время выполнения.

В журнале `result` = `ERR` означает, что контроллер не ответил: как правило,
это отсутствие связи с транспортным сервером или с самим контроллером.
Результат и журнал также попадают в лог приложения
(`application/logs/<год>/<месяц>/<день>.php`, уровень NOTICE: команда, пользователь,
список `ID_DEV`).

## Возможные сообщения {#devices-groups-messages}

| Сообщение | Причина и что делать |
| --- | --- |
| Неверный или устаревший CSRF-токен | Страница была открыта давно. Обновите страницу и повторите выбор |
| Не выбрано ни одной точки прохода | Не отмечены ни группы, ни точки прохода, и пусто поле `ID_DEV` |
| Неизвестная команда управления точкой прохода | Команда не передана или передана с опечаткой — обновите страницу |
| Среди выбранных устройств нет ни одной точки прохода | Указанные `ID_DEV` не являются точками прохода либо отмеченные группы пусты. Сверьтесь со списком точек прохода на странице |
| В журнале `ERR` по точкам прохода | Нет связи с ТС-сервером или контроллером. Проверьте ТС и линию связи (раздел «Настройка → ТС»), затем повторите команду |
