# Модуль devices — устройства, точки прохода и группы точек прохода {#devices-index}

## Назначение {#devices-purpose}

Модуль **devices** — это рабочее место администратора СКУД для работы с
оборудованием Артонит:

- список контроллеров и точек прохода (таблица, дерево, матрица);
- добавление, редактирование и удаление контроллеров вместе с их точками прохода;
- выполнение команд управления для **набора точек прохода** — по группам устройств,
  по списку отмеченных точек прохода или по перечню `ID_DEV`;
- то же самое из командной строки (Minion-задача `devices:door`) — для ручного
  запуска и для планировщика Windows.

Точка прохода — это устройство (`DEVICE`) со заполненным полем `ID_READER`
(канал контроллера: `0` или `1`). Именно для точек прохода выполняется команда
«открыть», «закрыть», «разблокировать».

## Страницы модуля {#devices-pages}

| Адрес | Назначение | Права |
| --- | --- | --- |
| `devices` | Список контроллеров и точек прохода: таблица, дерево, матрица | любой авторизованный |
| `devices/add` | Добавление контроллера с двумя точками прохода | администратор |
| `devices/edit/<id>` | Редактирование контроллера и его точек прохода | администратор |
| `devices/delete/<id>` | Удаление контроллера вместе с точками прохода | администратор |
| `devices/groups` | **Управление группами точек прохода** — команды для набора точек прохода | администратор |

Страницы `add`, `edit`, `delete` работают с одной **точкой прохода** (или одним
контроллером). Страница `devices/groups` работает с **набором** точек прохода —
это основной инструмент массовых операций.

## Как открыть {#devices-open}

1. Войдите в систему под учётной записью с ролью **admin**.
2. Откройте раздел **«Устройства»** (`devices`).
3. В верхней панели страницы нажмите кнопку **«Группы точек прохода»**.

Состав групп устройств (какие точки прохода в какую группу входят) настраивается
в отдельном разделе — **«Группы устройств»** (`devgroup`).

## Разделы справки {#devices-sections}

- **[Группы точек прохода](groups)** — как выполнить команду для набора точек
  прохода из браузера: выбор группы, выбор точек прохода, перечень `ID_DEV`,
  результат и журнал выполнения.
- **[Настройка CLI (Minion)](cli)** — как запускать те же команды одной строкой
  из командной строки: задача `devices:door`, её опции, проверка связи с
  транспортным сервером, коды возврата.
- **[Задача в планировщике Windows](scheduler)** — как поставить команду в
  расписание (например, разблокировать входную группу утром и закрыть вечером).

## Требования {#devices-requirements}

- Включённые модули `devices`, `devgroup` (состав групп) и `minion` (запуск из
  командной строки).
- Доступ к базе СКУД через подключение `fb` (DSN `ilove`).
- Для управления точками прохода — роль **admin**.
- Для реального выполнения команд — доступность **транспортного сервера (ТС)**,
  через который работают контроллеры: команда уходит на ТС, а тот передаёт её
  контроллеру.

[!!] Команды управления выполняются немедленно. Команды «Открыть навсегда» и
«Закрыть навсегда» меняют режим точки прохода до следующей команды — применяйте
их осознанно, особенно для целых групп.
